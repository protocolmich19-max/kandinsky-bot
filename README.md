# Loyalty API

Небольшое Flask-приложение для регистрации клиентов и партнёров, публикации продуктов и покупок с начислением скидочных баллов.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Сервис слушает на `http://0.0.0.0:8080`.

## Эндпоинты

### POST /register/client
Создать клиента с стартовым балансом 500 000 баллов.

Пример тела:
```json
{ "name": "Иван" }
```

Ответ:
```json
{ "id": 1, "name": "Иван", "points": 500000 }
```

### POST /register/partner
Создать партнёра.

Тело:
```json
{ "name": "Окна+" }
```

### POST /products
Опубликовать продукт партнёра.

Тело:
```json
{ "partner_id": 1, "name": "Установка окна", "price": 35000 }
```

### GET /products
Список всех продуктов.

### POST /purchase
Совершить покупку и применить скидочные баллы.

Тело:
```json
{
  "client_id": 1,
  "product_id": 1,
  "redeem_points": 2000
}
```

Логика скидок:
- Клиент начинает с 500 000 баллов, максимум на балансе тоже 500 000.
- С каждой покупкой начисляется 1 000 баллов (не превышая максимум).
- Баллы можно списать в поле `redeem_points`; 1 балл = 0.01 валютной единицы скидки.
- Итоговый ответ показывает применённую скидку, финальную цену и текущий баланс.

### GET /clients/<id>
Получить информацию о конкретном клиенте и его балансе баллов.
